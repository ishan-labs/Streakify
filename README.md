# Streakify
I designed and coded Streakify, a minimalist productivity web application built to help users stay motivated by tracking their daily habit streaks. The primary focus of the project was creating a clean, high-quality user interface that completely eliminates visual friction, making it as easy as possible for users to log their progress.
